# Mind Care Adventure 🎮💙

Mind Care Adventure is an interactive web-based game designed to promote mental wellness through fun gameplay, character selection, and engaging challenges. Players embark on a journey of self-discovery while enjoying a visually rich and immersive experience.

## 🌐 Live Demo

Try the app here:  
[Mind Care Adventure Live Demo](https://mind-care-adventure.vercel.app/)

## 🚀 Features

* 🎭 Character selection system
* 🎮 Interactive game gameplay flow
* 📊 Result/feedback screen at the end of gameplay
* 🌙 Smooth UI with modern animations and design
* 💡 Focus on mental wellness awareness through play

## 🛠️ Tech Stack

* Next.js (App Router)
* React
* TypeScript
* Tailwind CSS
* Vercel (Deployment)

## 📁 Project Structure

* `app/page.tsx` – Main entry and game routing
* `components/` – UI components (Main Menu, Game Canvas, Results, etc.)
* `lib/game-context` – Game state management
* `components/ui` – Reusable UI elements

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/mind-care-adventure.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

Then open:

```
http://localhost:3000
```
